**名画真人化的分镜创作操作系统。不是提示词模板，是可运行的短片叙事框架。**

从一幅静止的名画出发，倒推它前后发生过什么，
写出 Seedance 2.5 能执行的分镜提示词，前段真人实景演出，末帧变回原画本身。

**双重交付**：提示词（直接复制进视频模型）+ 创作手法（直接拿去当自媒体文案）。

## 效果示例

> 输入一张《戴珍珠耳环的少女》，下面是技能交付的节选。

### 交付一：创作手法（节选）

```
故事从画外开始。少女不是一开始就回头的，她刚把桌上的信折好，
听见身后有人推门，回头的那个瞬间才是原画。

入口选在窗边的桌面，镜头先拍她折信的手，再顺着她的转身带到脸上。
情绪线是被打断的私密感：她本想独处，来人让她重新回到社交状态，
回头时那种介于惊讶和克制之间的表情，就有了来处。

结尾前摄影机退回到原画的观察位置，人物、头巾、珍珠、背景的暗部
逐项归位，最后 1 秒定住画面，只把皮肤和布料转成维米尔的油画笔触。
```

### 交付二：提示词（节选）

```提示词
生成视频：真人电影质感，17 世纪荷兰代尔夫特室内，午后窗光。总时长 30 秒。
前 29 秒保持真人演员与真实场景质感；最后约 1 秒逐渐转化为输入原画《戴珍珠耳环的少女》本身。

@Image 1 用于确定人物外形、蓝色头巾、珍珠耳环、侧身回眸姿态、暗色背景和最后一帧构图。
故事核心：少女在窗边折好一封私密的信，被推门声打断，情绪从松弛独处
转为克制的警觉，最终定格成回眸的瞬间。

【0到4秒｜窗边折信】
摄影机从桌面的信纸特写开始，自然窗光从左侧进入。少女双手把信纸
折成小方块，指尖停顿了一下。环境声只有纸张摩擦和窗外远处的风车声。

【4到10秒｜推门声】
摄影机从她手部平稳移到肩后。画外传来木门轴转动的声音，她手指一紧，
信纸压在掌下。她没有立刻回头，先侧耳听了两秒。

【10到18秒｜回身】
她从椅子上半转过身，蓝色头巾的布料随动作轻晃。摄影机绕至她侧前方，
她的视线越过肩头看向门口方向，嘴唇微张。

【18到26秒｜对视与收敛】
她的表情从惊讶收敛为平静，下颌微收，眼神定住。摄影机缓慢后撤。

【26到30秒｜对齐原画并转化】
摄影机调整至与参考图相同的观察方向、高度与距离。人物回到侧身回眸
的姿态，珍珠耳环位于画面右中部，头巾蓝色垂布在左肩，背景暗部
与原画对应。构图完成后摄影机停止，人物与环境保持稳定。
最后约 1 秒，只让皮肤、布料与背景的材质和色彩转化为维米尔的
油画笔触，柔和连续，不重新取景。最后一帧呈现输入原画本身。

【约束】
禁止人物增减、肢体异常、现代物件、文字水印。
前段保持真人电影质感，油画笔触只在最后转换段出现。
```

> 一次交付完整两部分，创作手法讲清故事来处和镜头动机，提示词直接能跑。

## 创作了什么

### 一个核心方法：从画面倒推时间

| 静态的画 | 动态的片 |
|---------|---------|
| 人物定格在一个姿态 | 姿态是某段行动的终点 |
| 画面内只有当下 | 镜头可以走进画外空间 |
| 观众自己脑补前后 | 提示词把前后写成可执行的动作 |

**三个关键问题：**
1. 这个姿态是动作开始前、进行中，还是结束后？
2. 画外哪里能自然走进这个场景？
3. 观众先看到什么，才能读懂这个瞬间？

### 四段式分镜结构

1. **入口** → 局部、脚步、手、声音或画外空间
2. **发现** → 镜头带出人物与原画场景
3. **情绪节点** → 一个可见的停顿、选择或关系变化
4. **收束** → 逐项对齐原画构图，末秒转质感

### 结尾的两步分离

- **倒数 3 到 4 秒**：真人场景逐项对齐构图锚点（人物方位、姿态、道具、地平线）
- **最后约 1 秒**：画面定住，只转材质和色彩，不动镜头和人物

这是整条提示词最容易翻车的地方，技能里专门写了失败修正对照表。

### 反模式（绝对不会做）

- 前段反复强调油画质感，把真人片拍成幻灯片
- 只写镜头缓慢横移，没有任何人物行动
- 一边要求末帧复现原作姿势，一边禁止构成该姿势的动作
- 把创作性对白和人物关系写成艺术史事实

## 能改什么

丢需求的时候可以顺手带上这些参数：

- **故事方向**：想从哪切入，谁和谁是什么关系
- **时长**：默认 30 秒，也能指定
- **对白语言**：不指定就按画里的地点、时代、人物定
- **镜头偏好**：平滑运镜、跟拍为主、特写为主都行
- **改稿**：直接说哪不对，比如结尾转原画太快、第二段动机不明

还有一件事技能会替你把住：画作没交代的人物身份和关系，它会写成创作性设定并标注出来，不会混进史实里。拿去做内容，这个边界值得保留。
