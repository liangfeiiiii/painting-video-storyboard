# painting-video-storyboard

名画真人化视频分镜创作 Skill，服务于 Seedance 2.5。

事情的起点很简单。一幅名画是静止的，但画里的人原本在过日子。蒙娜丽莎坐下之前走过那条路，撑阳伞的女人从远处一路走来才停在草坡上，戴珍珠耳环的少女回头之前在看别的东西。这个 Skill 干的就是把这些前后文补上，写成视频模型能执行的分镜提示词，让静态画面长出一段有开头、有起伏、有落点的短片。

## 它做什么

你给一张名画（可以再配点背景资料），它产出一份 Seedance 2.5 提示词，结构上是这样：

- 前段真人演员实景演出，皮肤、服装、光线、动作都按真实世界来
- 中间是有情节的短故事，人物有行动、有关系变化，不是摆姿势给你看
- 倒数几秒让真人画面逐项对齐原画构图，人物、道具、地平线都归位
- 最后约 1 秒画面定住，只把材质和色彩转成原画笔触，最后一帧就是原画本身

同时附一份「创作手法」，讲清楚故事为什么这么编、镜头为什么这么走，拿去当自媒体文案直接能用。

## 怎么装

把 `painting-video-storyboard` 整个文件夹丢进你的 Agent 技能目录就行。Claude Code、Codex、WorkBuddy 这类工具都认 `SKILL.md` 这个约定。

装好之后丢一张名画过去就能触发，说「名画真人化」「给这幅画写视频提示词」「名画 Seedance 提示词」这些也行。

## 能调的参数

- 故事方向：想从哪切入，谁和谁是什么关系
- 时长：默认 30 秒，也可以指定
- 对白语言：不指定就按画里的地点、时代、人物来定
- 镜头偏好：平滑运镜、跟拍、特写为主都可以要求
- 改稿：直接说哪里不对，比如「结尾转原画太快」「第二段人物动机不明」

## 用的时候留意

这个 Skill 内部会把艺术史事实和剧情创作分开。画作没交代的人物身份、关系、对白，它会写成创作性设定，但不会伪装成史料。你拿去做内容的时候，这个边界也建议保留。
